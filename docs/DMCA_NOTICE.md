## 1. Notice of Non-Hosting & Non-Service Provider Status (17 U.S.C. § 512)

**RenegadeSwarm** is free, open-source, client-side software designed for decentralized, peer-to-peer (P2P) distribution of generative AI model weights. 

The software developers, maintainers, copyright holders, and GitHub repository administrators:
1. **Are NOT a Service Provider / Host**: We do **not** operate a hosting service, web platform, centralized database, cloud storage repository, or content distribution network (CDN) within the meaning of the **Digital Millennium Copyright Act (DMCA), 17 U.S.C. § 512(c)**, or Article 14 of the **EU Electronic Commerce Directive / Digital Services Act (DSA)**.
2. **Zero Custody of Content**: We **do not host, cache, transmit, index, seed, or possess** any AI model checkpoints, LoRAs, UNet weights, datasets, or user files.
3. **Decentralized Operation**: File transfers occur directly between autonomous, decentralized end-user endpoints over the BitTorrent protocol and the Mainline Distributed Hash Table (DHT).

## 2. Notice of Technical Impossibility Regarding Takedowns

Because RenegadeSwarm is fully decentralized, client-side software with zero centralized infrastructure:

* **No Administrative Control**: The developers possess **no technical ability, administrative credentials, master killswitch, or server-side access** to monitor, intercept, block, remove, or delete files from remote users' computers or across the P2P swarm.
* **Takedown Requests Cannot Be Executed**: Submitting a DMCA takedown notice, cease-and-desist letter, or statutory removal demand to the open-source software developers demanding the removal or deletion of a model from the decentralized network is **technically impossible to fulfill**.
